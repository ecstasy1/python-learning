# Lesson 3 Notes — Terminal & Bash Basics

## Terminal / CLI
A text-based way to communicate with the computer using commands.

## Working Directory
The folder I am currently inside.

## Path
The location or address of a file or folder.

## Python Interpreter
The program that reads and runs Python code.

## Commands

- `pwd` — shows my current location.
- `ls` — shows the contents of my current folder.
- `cd` — changes my current folder.
- `cd ..` — moves one folder up.
- `mkdir` — creates a new folder.
- `touch` — creates a new file.
- `python3` — runs Python code.

## PATH
A list of locations where the computer looks for executable programs.
