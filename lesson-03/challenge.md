## 1. What is a terminal?

## 2. What does `pwd` do?

---Shows the folder i am in

## 3. What does `ls` do?

---Shows the contents of my current folder.

## 4. What does `cd` mean?

---change directory

## 5. What does `cd ..` do?

---Go one folder up.

## 6. What is the difference between a file and a folder?

---A folder can contain files and other folders. A file contains information or code.

## 7. What does `mkdir` do?

---creates a new folder

## 8. What does `touch` do?

---creates a new file

## 9. What is a path?

---the location/address of a file or folder.

## 10. What does the Python interpreter do?

---The Python interpreter reads and runs Python code.

## 11. What is PATH?

---PATH is a list of locations where the computer looks for executable programs.
