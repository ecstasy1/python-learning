# Lesson 2 - Introduction to Python (Why Python)

## What is Python?

### Definition
Python is a high-level programming language that is easy to read, write, and understand.

### Simple Explanation
Python lets humans give instructions to computers using words that are easier to understand than machine language.

### Example

```python
print("Hello, World!")
```

---

## High-Level Language

### Definition
A high-level language is a programming language that is close to human language and easy to read.

### Simple Explanation
Instead of speaking in 0s and 1s, we write code that looks almost like English.

### Example

```python
print("Python is fun!")
```

---

## Low-Level Language

### Definition
A low-level language is closer to the computer's hardware and is harder for humans to read.

### Simple Explanation
Computers understand machine language. Low-level languages are much closer to that than Python.

---

## Readability

### Definition
Readability means writing code that is easy for humans to read and understand.

### Simple Explanation
If another programmer can quickly understand your code, it has good readability.

### Example

```python
print("Welcome!")
```

---

## Library

### Definition
A library is a collection of pre-written code that programmers can use in their own programs.

### Simple Explanation
Instead of writing everything yourself, you can use code that has already been created and tested.

### Example

```python
import math
```

---

## Versatility

### Definition
Versatility means that Python can be used for many different types of programming tasks.

### Simple Explanation
You can use Python to build websites, games, AI, automation tools, and much more.

### Examples

- Web development
- Artificial Intelligence
- Data Science
- Automation
- Game development


---

## SyntaxError vs NameError

### SyntaxError

A SyntaxError happens when Python cannot understand the structure or grammar of the code.

Example:

```python
print(Hello, World!)
```

### NameError

A NameError happens when Python encounters a name that has not been defined or is not recognized.

Example:

```python
print(Hello)
```

### Easy way to remember

- **SyntaxError** = Python doesn't understand the **structure**.
- **NameError** = Python doesn't know the **name**.
