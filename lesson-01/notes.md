# Lesson 1 – Introduction to Python

## Objective
Learn how to run a Python program and understand the basics of `print()`.

## New Concepts

### Python
Python is a programming language used to create software, automate tasks, analyze data, build websites, and develop AI applications.

### Program
A program is a set of instructions that tells a computer what to do.

### Python Interpreter
The Python interpreter reads and executes Python code one line at a time.

### print()
`print()` is a built-in function that displays output on the screen.

### String
A string is text enclosed in quotation marks.

Example:

```python
print("Hello")
```

### Syntax
Syntax is the set of rules for writing valid Python code.

### SyntaxError
A SyntaxError occurs when Python cannot understand the code because it breaks Python's syntax rules.

### NameError
A NameError occurs when Python tries to use a name that has not been defined.

## What I Learned Today

- Python executes code from top to bottom.
- Quotation marks tell Python that something is text.
- `print()` displays output on the screen.
- Reading error messages is an important programming skill.
- Making mistakes is part of learning.
